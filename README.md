# simple-boids-like

boidの群れを1つの共有プログラムで操作し、資源収集・拠点防衛などを解いていく
ゲームのアイデアを検証するためのプロトタイプ。

## ゲームの核

- 世界は2次元平面。boidは絶対位置ベクトルと絶対速度ベクトルを持つが、
  **プレイヤーが書く1つのプログラムが全boidを動かす**。
- 1体のboidがアクセスできる情報は「自分の速度」と「視界内にいる他boid・資源・
  拠点の、自分を原点とした相対位置・相対速度」だけ。**絶対位置は一切わからない。**
- この情報制限のもとで、プレイヤーは意図した創発（boid同士の協調）を起こす
  ようにプログラムを書く必要がある。そこが難易度でありゲーム性の核。
- 将来的にはfactorio / shapez.io / mindustry的な資源収集・基地拡張・研究・
  戦闘を、このboidプログラミングで解いていくことを目指している。

## 現状

「そもそも解けるか」「解く過程が面白いか」を検証する**Phase 0**の段階。
5つの検証シナリオ（収集・搬入 / 隊列・陣形維持 / 中継リレー輸送 / 補給網拡張
（ラダー）/ 補給線輸送）に加え、実験的な6つ目のシナリオ（広域探索・フェロモン
なし）を実装済み。全体のロードマップと現状の詳細は
[docs/roadmap.md](docs/roadmap.md) を参照（中継リレー輸送は既知の理由で
現在勝利できない状態、広域探索は確率的にしか勝てない実験段階、詳細はroadmap
参照）。

## セットアップ・起動

```sh
npm install
npm run dev
```

表示されるURL（`http://localhost:5173/`）をブラウザで開く。上部のボタンで
5つのシナリオを切り替えられる。
